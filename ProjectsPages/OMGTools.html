PERSONAL PROJECT

OMG Tools

Tools for creating and editing game cards, alongside an experimental combat system.

  • Unity
  • C#
  • PC
  • Editor Tools

Overview

Embarking on a journey inspired by Ankama's "One More Gate: A Wakfu Legend," I delved into the intricacies of game development, particularly intrigued by how a small team of two developers could craft such a comprehensive experience. This curiosity led me to create tools aimed at streamlining the development process.


My initial focus was on a card creation and modification tool. This tool allows for the design and adjustment of in-game cards, providing flexibility in gameplay mechanics and facilitating rapid prototyping.


Building upon this foundation, I began developing the combat loop, the core system that governs player interactions and battles within the game.


These tools are designed to enhance efficiency and creativity in game development, offering a streamlined approach to crafting complex game elements. By sharing this project, I aim to contribute to the broader game development community, providing resources that can assist others in their creative endeavors.

Technical environment

  • Language: C#
  • Platform: PC (Windows)
  • Focus: Custom Editor Tools & Systems Architecture
