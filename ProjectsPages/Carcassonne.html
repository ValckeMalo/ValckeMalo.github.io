Overview

Carcassonne - Tiles & Tactics is the official digital adaptation of the famous modern board game classic. Built in Unity, the game brings the beloved tile-placement mechanics to life on PC and mobile platforms. Players strategically build a medieval landscape featuring cities, roads, abbeys, and fields, placing their followers (meeples) as knights, monks, robbers, or farmers to score points and outsmart opponents.

Technical environment

  • Engine: Unity
  • Language: C#
  • Store & Services: Google Billing API, Unity IAP (In-App Purchases)
  • Studio: Artefacts Studio

My contributions

As part of my professional experience at Artefacts Studio, my work on Carcassonne focused on core code maintenance and system updates:


  • Android Version Maintenance: Handled backend code maintenance and updates for the Android version to ensure long-term stability and compliance with platform standards.

  • In-Game Store Update: Upgraded and refactored the in-game store integration using Google's billing API and Unity IAP to secure transactions and meet modern store requirements.
