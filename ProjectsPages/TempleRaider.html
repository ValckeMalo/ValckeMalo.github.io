Temple Raider

A solo puzzle game project using Unreal Engine 5, C++ and Blueprints.

  • Unreal Engine 5
  • C++
  • Blueprints
  • Puzzle Game

Overview

Over the course of several weeks, I undertook a project to create a puzzle game using Unreal Engine 5, combining C++ and Blueprints to implement the core gameplay mechanics. This exercise was designed to deepen my understanding of Unreal's scripting systems while crafting a game that emphasized logic and creativity.


The puzzle game centered around mechanics such as:
• Interactive objects, like levers, pressure plates, and movable blocks, which players could manipulate to solve challenges.
• Dynamic level mechanics, where player actions directly altered the environment, unlocking new paths or activating mechanisms.
• A system for progression tracking, ensuring puzzles became more challenging as the player advanced through levels.


This project allowed me to blend C++ and Blueprint workflows, providing valuable insights into the strengths of each system. It also honed my ability to design puzzles that balance challenge and accessibility, ensuring an engaging experience for players.

Technical environment

  • Engine: Unreal Engine 5
  • Languages: C++ & Blueprints
  • Focus: Core Gameplay Mechanics, Environmental Interaction, Puzzle Level Design

My contributions

In this solo project, I worked on:


  • C++ Gameplay Programming: Core gameplay mechanics in C++, such as player-object interactions and game logic, ensuring efficiency and flexibility.

  • Blueprint Prototyping: Leveraging Blueprints to rapidly prototype and iterate on puzzles, fine-tuning gameplay and testing new ideas.

  • Level & Puzzle Design: Designing and implementing puzzle levels, crafting scenarios that required logical thinking and experimentation to solve.
