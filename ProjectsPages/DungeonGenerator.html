Dungeon Generator

A procedural dungeon generation project exploring level generation and room connections.

  • Unity
  • C#
  • Procedural Generation

Overview

Inspired by the intricate yet engaging gameplay mechanics of The Binding of Isaac, I set out to recreate one of its most iconic features: dungeon generation. This standalone project focuses on simplicity while preserving the essence of procedural exploration that defines the game.


The goal was to design a streamlined system capable of generating:
• Procedurally connected rooms that mimic the branching paths of a dungeon.
• A simplified map display for player navigation, representing discovered and undiscovered areas.
By focusing on these two elements, I aimed to capture the feeling of exploration and mystery while keeping the implementation manageable and focused.


Through this project, I gained hands-on experience with procedural generation and the balance between randomness and playability. The simplified map system taught me the importance of player feedback in navigation and discovery, essential for maintaining immersion. This project stands as a testament to how core gameplay mechanics, even when isolated, can still offer depth and engagement.

Technical environment

  • Engine: Unity
  • Language: C#
  • Core Concepts: Procedural Generation, Room Connection Algorithms, UI Minimap Tracking

My contributions

As a solo developer on this project, I handled all aspects of design and programming:


  • Algorithm Design: Designed the generation algorithm to ensure randomness and replayability while maintaining logical connectivity between rooms.

  • Map System UI: Built the map system, which updates dynamically based on the player’s exploration, providing a minimalist yet functional interface for tracking progress.
