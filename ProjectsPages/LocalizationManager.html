Localization Manager

A C# and WPF tool for managing localization data and exporting it to CSV, JSON, XML, C# and C++.

  • WPF
  • C#
  • CSV
  • JSON
  • XML

Overview

Embarking on a collaborative journey in a school exercise, my team and I faced the challenge of creating a localization manager using WPF in C#. This project required us to develop a tool that simplifies the management of multilingual applications, catering to both developers and content managers.


The localization manager serves as a versatile tool that allows users to:
• Add language keys and values to create a dynamic spreadsheet-like interface.
• Import data from CSV, JSON, and XML formats for seamless integration.
• Export data in the same formats (CSV, JSON, XML) for maximum compatibility.
• Generate usable classes in C# and C++ for straightforward integration into multilingual applications.

Technical environment

  • Framework: WPF (Windows Presentation Foundation)
  • Language: C#
  • Data Formats: CSV, JSON, XML
  • Target Code Generation: C# & C++ classes

My contributions

My contribution focused on designing and implementing the export functionality, which bridges the gap between data input and its practical use in real-world applications.


I spearheaded the development of the export class, which is the backbone of the tool’s usability. This component:

  • Processes structured data entered by the user.
  • Ensures compatibility with both C# and C++ environments.
  • Generates clear, efficient, and ready-to-use class files, making the localization manager invaluable for developers.

Impact and Learnings: This project strengthened our problem-solving and teamwork skills. By handling the export class, I gained insights into converting structured data into usable code while balancing user needs with technical constraints.
