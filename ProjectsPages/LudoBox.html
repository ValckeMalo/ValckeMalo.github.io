LudoBox

An ambitious cross-platform board game companion app built with .NET MAUI, C#, Supabase, PostgreSQL, and deep BoardGameGeek API integration.

  • .NET MAUI
  • C# / MVVM
  • Supabase
  • PostgreSQL
  • BoardGameGeek API
  • Mobile & PC

Overview

LudoBox is a comprehensive, cross-platform companion application designed specifically for board game enthusiasts. Targeted primarily at Android mobile devices while maintaining full cross-platform compatibility with PC, LudoBox bridges the gap between digital collection management and physical board gaming. The application serves as an all-in-one ecosystem allowing players to explore vast databases, track their personal libraries, discover new titles through intelligent randomization, and interact with a community-driven cloud backend.


The user experience is meticulously structured around 5 core pillars, seamlessly accessible via a modern bottom navigation toolbar:


  • Home Dashboard: Features dynamic game carousels categorized by smart criteria, such as daily and weekly rotating lists, trending hits, and real-time new releases. Each category is displayed in smooth, draggable horizontal rows equipped with 'View All' shortcuts that bridge directly into filtered search queries.

  • Random Discovery Engine: A dedicated serendipity tool where users configure specific filters (player count, mechanics, duration, and complexity) to instantly generate a randomized game recommendation that opens its complete profile sheet.

  • Advanced Search & Database: A robust database grid powered by a top-tier search bar and an expansive filtering matrix. Users can filter by player count, game duration, weight/complexity, mechanics, and thematic categories. Dropdowns handle precise single or multi-selections, accompanied by an instant master-reset trigger.

  • Virtual Library Showcase: A visual paradigm shift representing physical board game boxes arranged dynamically on customizable virtual shelves. Each box reflects real-world scale proportions and acts as an interactive portal to the game's detailed sheet, complete with customizable seasonal or holiday background themes.

  • User Profile & Community Hub: Centralizes account management through statistical breakdown grids (owned games, rated titles, wishlist size, played counts), custom lists (Wishlist, Owned, Played), favorite shortcuts, and a chronological feed of community reviews with deep-linking capabilities.

Technical Environment & Architecture

LudoBox is architected as a modern, scalable full-stack ecosystem leveraging cutting-edge frameworks for high performance on both mobile and desktop environments:


  • Client Framework: Developed using .NET MAUI (C#) adhering to MVVM design patterns, ensuring native rendering, high fluidity, and clean separation of concerns across Android and Windows targets.

  • Cloud Backend & Database: Powered by Supabase and PostgreSQL, utilizing relational tables, secure schema views, and robust Row-Level Security (RLS) policies for user data protection.

  • External Data Pipeline: Custom C# background routines and REST API integration consuming data feeds from BoardGameGeek (BGG) to continuously parse, normalize, and feed the local repository.

  • Tooling & Prototyping: UI layouts meticulously prototyped in Figma and translated into responsive MAUI XAML components, supported by custom Visual Studio extension services for seamless endpoint querying.

My Contributions & Technical Ownership

As the sole creator and architect of LudoBox, I handled every layer of the development lifecycle, demonstrating end-to-end technical mastery:


  • Full-Stack Backend Engineering: Provisioned and structured the Supabase PostgreSQL database, designing optimized schemas, relational foreign keys, and secure authentication flows linked directly to table views.

  • Data Ingestion & BGG Pipeline: Engineered automated extraction tools to retrieve raw board game datasets from the BoardGameGeek API, processing complex XML/JSON structures to populate the relational database cleanly.

  • Cross-Platform UI/UX Implementation: Translated Figma design systems into reactive .NET MAUI views, building custom controls, fluid bottom navigation bars, data bindings, and adaptive layout grids for optimal mobile usability.

  • API Extension Services: Developed specialized service layers and Visual Studio extensions in C# to abstract HTTP requests and seamlessly communicate with Supabase endpoints from the mobile client.
