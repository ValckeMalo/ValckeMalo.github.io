PERSONAL PROJECT · IN DEVELOPMENT

LudoBox

A cross-platform application for tracking a board game collection, inspired by services such as Letterboxd and TV Time.

Technologies

C# · .NET MAUI · Supabase · PostgreSQL · BoardGameGeek API

Current features

  • User registration and login.
  • PostgreSQL database with related tables.
  • Integration with the BoardGameGeek API.
  • First version of the user interface.

Goals

This project lets me explore application development beyond game engines.

The application is still in development.
